另一次诊断发现 Codex 更新流程，立即停止自建会话；随后 Codex 版本仍为 0.160.1，配置哈希未变，不声称 Homebrew 元数据完全未动。关闭本次启动更新检查后，Codex 开始任务，但执行器报 `sandbox_apply: Operation not permitted`，并明确停止等待权限处理。临时诊断测试已删除，所有测试会话均已清理。

已给出 [待授权的替代测试方案](codex-integration-followup.md)：保留 Codex 自身 workspace-write/on-request，不叠加外层 sandbox-exec；明确失去的外层只读保护，不修改全局配置/共享 daemon，不升级、不自动同意提示。原授权要求遇权限提示停止，因此在回复前不执行依赖该变更的测试。后续还需补齐启动更新/执行器报错的测试阻断识别，避免自动测试向非任务输入框投递。

这与用户此前报告的 `application network permission was revoked` 不是同一条已复现错误；当前证据不足以将两者归为同一根因。
