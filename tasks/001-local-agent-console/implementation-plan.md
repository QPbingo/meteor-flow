# 实现计划与验收映射

状态：技术方案 0.2 已由用户于 2026-10-06 确认并要求开始实现。适用：[需求 0.2](requirements.md) 与 [技术方案 0.2](technical-design.md)。下列步骤与测试均是计划，实际进度见 [实施进度](implementation-progress.md)，不把计划视为执行证据。

## 1. 实施顺序

| 步骤 | 产出 | 进入下一步的依据 |
| --- | --- | --- |
| P0 开发准备 | capture-constraints 开发前检查；固定 Node 24/pnpm/依赖，核对原生模块及 SQLite 实际版本；项目级 Playwright、Impeccable 的完整引入、锁定、双端入口与实际能力探针；test-master/OCR 已加载能力复核 | 适用技能全部就绪；技术方案已获确认。临时 Node 能力探针不等于整个产品环境已就绪 |
| P1 状态与存储 | pnpm workspace、共享 schema、SQL 迁移、单一 DB worker、POSIX 锁、项目/任务/attempt、命令去重、依赖图、事件记录 | 隔离 DB/文件/进程测试，终态及占用不变量成立；DB 确认丢失时停止派发，不重试外部命令 |
| P2 herdr 管理 | 明确 session、版本能力、观察接入、独立目录、启动 intent、JSON API、事件与身份校准 | 契约与故障模拟通过；独立测试 session 的真实接口可用 |
| P3 调度与结果 | 队列筛选、输入冻结、一次投递、取消/重试、结果协议、安全采集、不可变归档 | 控制时序与进程崩溃用例验证；不重发、不串归属 |
| P4 网页与终端 | 所有主页面、只读/接管/释放、认证与 CSRF、双页面控制、预览与下载 | Playwright 操作及后台持久化核对；Impeccable 技术和体验审查 |
| P5 恢复与真实集成 | 重启/断线/休眠、磁盘/负载、真实 Codex/Claude 文件交付与人工介入 | 真实 herdr 证据单列；环境缺失的用例保持 blocked |
| P6 完整复验 | V01—V29、六类场景、独立 OCR review、修订复查、记录检查、启动说明 | 无未关闭 critical/high；证据齐全后交人工验收，agent 不签署 accepted |

所有产品代码放正常源码目录；方案继续维护本目录；`verification-runs/` 只存报告和证据。验证子进程使用专用临时目录、临时数据库、动态端口、明确的测试 herdr session，不向用户现有 agent 投递测试任务。

## 2. 测试分层

1. Vitest 纯业务单元：状态转换、等待原因、DAG、幂等键、结果协议与运行时 schema。外部接口使用可控 fake，不把 mock 结果称为集成。
2. 隔离集成：真实 better-sqlite3/DB worker、真实文件与符号链接、Koffi/OS 锁、进程退出、真实端口 HTTP/WS；Fastify inject 用于路由检查，不替代网络验证。可控 herdr 模拟服务验证部分输入、响应丢失与事件乱序。
3. 浏览器 E2E：真实 Meteor Flow HTTP/DB/归档，固定模拟器做竞争与异常；每项断言浏览器状态和后台副作用次数/数据关系。
4. 真实 herdr：显式独立 session、独立目录、已安装的 Codex/Claude；验证启动、结果、终端、取消与重连。缺登录或会话条件时记录具体阻塞，不降格成已通过。
5. UI：Impeccable audit 覆盖键盘、焦点、主题、响应式、性能；critique 检查等待原因、失败恢复、控制权与结果归属是否可理解。执行时使用该固定版本要求的独立上下文。
6. 独立 OCR reviewer 读取当前需求、方案、代码、测试与调用链，保留 preview/rule 与逐文件范围；作者负责修复后交 reviewer 复查。

## 3. 六类强制场景

| 类别 | 前置与操作顺序 | 预期业务/副作用 | 需求与验收 |
| --- | --- | --- | --- |
| state-transition | 本地无占用但 agent working；用 barrier 在输入准备期间 idle→working；已投递后先 idle 无结果，再有效结果但仍 working | 前两项 prompt 次数为 0；无结果不成功；仍运行不释放占用；只有完整条件才能终态 | R01/R03/R04/R05/R06/R07；V05/V08/V09/V10/V12/V15 |
| idempotency | 双页面同 operation_id；不同 operation_id 同时重试；第二服务打开相同数据目录 | 一次逻辑操作、一个占用、最多一次 prompt；第二调度者被 OS 锁拒绝 | R02/R03/R06；V03/V04/V06/V26 |
| ordering | 用 barrier 控制取消事务先/后于终态；旧控制连接输入先/后于撤权；依赖修改与派发竞争 | 接受序号决定唯一结论；撤权后无输入；冻结输入不可变 | R06/R08/R09；V11/V13/V16/V18/V19 |
| recovery | 在 intent 后、外部输入后、归档 rename 后、DB 提交前分别终止进程；休眠/断线/磁盘满 | 重启先核对，不重放未知命令；不公开半成品；显示缺口与异常 | R02/R03/R11/R12/R13；V04/V05/V06/V24/V25 |
| association | 移动/替换 occupant；旧 attempt 迟到；上游成功后源文件改变；归档引用任务 | 位置变化不换身份；旧结果不盖新结果；下游固定 attempt/hash；引用可追溯 | R04/R05/R08/R11；V07/V09/V13/V16/V17/V28 |
| isolation | 同会话/目录、父子目录、符号链接目录、重复授权输出根；外站 HTTP/WS；产物路径替换 | 不启用冲突自动调度；不越界读取；跨站拒绝；测试不触及用户数据 | R09/R10/R11/R14；V18/V21/V22/V23/V26/V29 |

六类均适用于产品实现。本节是编码前定义的计划，不登记执行状态；2026-10-07 的实际分层覆盖和执行结果见 [验证状态](verification-status.md) 及其最终报告，未运行的物理环境场景不能由本表补签。

## 4. V01—V29 验收追踪

| 用例 | 验证方式与关键断言 |
| --- | --- |
| V01 | 真实 herdr + Playwright：网页创建 agent，完成文件任务；启动就绪后一次 prompt、正确 task/attempt、归档 hash |
| V02 | 真实手动启动 agent：缺少 interactive_ready 仍可完成接入核验；未经确认保持观察 |
| V03 | 两个 browser context 并发相同动作/网络重发：操作、attempt、prompt 次数均符合去重语义 |
| V04 | 在 herdr 接受 prompt 与响应记账间 kill 服务：恢复不重发，保留占用及待确认 |
| V05 | 模拟部分输入、timeout、残留；无本地占用但 agent working，以及 barrier 控制输入准备期间 idle→working：前置拒绝时 prompt 为 0，不自动再投递或清空 |
| V06 | 控制启动响应超时后出现进程：没有第二次 start，恢复识别或待确认 |
| V07 | 独立 session 移动 pane、替换 occupant、恢复旧会话：定位更新，调度授权不串实例 |
| V08 | idle/退出但无结果：待确认，无成功归档/下游派发 |
| V09 | 半 JSON、未知版本、缺产物、复制中文件变化：无成功发布；收集重试不发 prompt |
| V10 | 成功摘要与空 artifacts + 结束证据：正常完成 |
| V11 | 两个 barrier 顺序：取消先则迟到结果；成功先则取消无效 |
| V12 | 中断无效/停止证据不足：保留占用，重试/改派拒绝 |
| V13 | 第一次失败后安全重试，新 attempt 运行时旧结果到达：新状态不变，旧记录保留 |
| V14 | 队首依赖阻塞、后方独立任务可运行：后方派发；等待原因可见 |
| V15 | 业务 failed+agent 可用时独立任务推进；投递不明时同 agent 队列暂停 |
| V16 | 自环/跨项目/并发成环、revision 冲突、运行后编辑：API 拒绝且 DB 不出现非法边 |
| V17 | 固定上游 attempt/hash；改变工作文件/复制上游再执行：运行下游输入不变化 |
| V18 | 两个页面争夺控制、断线旧 token/input：只有有效 connection/epoch 能产生输入 |
| V19 | 原生处理审批后网页旧帧：无自动批准；重连旧输入不发送 |
| V20 | 分别关闭控制页面/观察页面：前者失权且暂停，后者不改变调度 |
| V21 | 真实路径重叠、符号链接别名、同 agent 会话、共同输出根：自动管理拒绝 |
| V22 | `..`、绝对路径、符号链接、硬链接、无 writer FIFO、设备文件、超限；barrier 控制目录→FIFO/符号链接替换：及时拒绝，未读取边界外内容，其他采集不被阻塞；覆盖结果 JSON 与输入源 |
| V23 | HTML、脚本、远程图片、SVG、巨大文本：无脚本执行/外网请求，页面可操作 |
| V24 | 断线/事件丢失/重启/时钟跳变：旧观测与旧输入失效，恢复扫描，身份不能确认则暂停 |
| V25 | 真实不可写目录 + 可控 ENOSPC/SQLITE_FULL 注入 + 输出负载：无未记录派发，紧急人工中断边界可见 |
| V26 | 两进程同 DB realpath、别名路径、多页面；两数据目录同 session：至多一个管理实例 |
| V27 | 未知服务端/协议/结果版本、缺关键身份字段、不支持 agent：能力降级/拒绝，不能伪称兼容 |
| V28 | 被依赖任务归档/删除请求：引用与下载不破坏；服务不提供级联删除 |
| V29 | 恶意 Origin/Host、无 Cookie/CSRF、跨站 WebSocket、外链产物：读取与副作用均拒绝 |

Node 方案另需覆盖下列具体机制，仍归入上述用例，不另改需求：

- V04/V24：用 barrier 将旧 DB worker 分别停在 commit 前、commit 后回复前且仍存活；主进程失去确认后使 storage generation 失效，迟到回复不产生副作用，未观察旧 worker exit 前没有第二 writer 或恢复派发。确认退出后按 operation/intent 核对，不重新调用 prompt。
- V22：真实 openat 逐级目录替换、叶子 FIFO、bigint 文件身份比较；结果文件、输入副本与产物使用相同边界。
- V09/V24/V25：采集子进程发完成消息后仍持写 fd、主进程崩溃但子进程存活、取消后迟到完成、IPC 中断与原生调用异常；用 barrier 控制完成/退出/取消次序。主进程可响应，未退出或已失效 job 不发布，重启后旧 staging 不复用或边写边清理，未回收进程及未决启动 intent 计入容量限制。
- V26：持锁主进程暂停、退出，以及采集/CLI 子进程仍活着的情形；不误抢锁，不因描述符继承长期阻塞重启。

每项最终补充准确命令、退出码、观察结果、测试资源与证据链接。源码/约束修订后创建新的最终复验记录，不能给旧日志替换基线。
