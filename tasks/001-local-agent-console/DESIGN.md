# 控制台界面实现依据

日期：2026-10-07。状态：依照已确认技术方案 §12 实施；具体排版为可逆实现选择，待真实界面审查。适用：apps/web。

模式：Operate。用户在本机管理指定 agent 的任务，必须随时知道连接是否新鲜、当前执行是否占用、为什么等待及如何恢复。

工作台采用固定侧栏、清晰任务表与可展开详情。浅灰工作区、白色表面、深墨色文字，低饱和蓝色表示当前选择；成功/警告/错误使用文字加图标，不单靠色彩。使用本机系统字体保证中文可读性，代码、路径与执行标识采用等宽字体；不添加无关插画、数据或装饰指标。

任务列表为首页主体；系统连接与暂停状态在顶部，项目/agent 在侧栏和独立页面管理。详情包含概览、冻结输入、终端、结果及时间线；终端默认只读，接管与恢复调度保持两个明确动作。无数据时提供当前缺少配置的下一步，错误保留表单并给出可执行恢复动作。

所有输入有可见标签和错误说明，按钮文案明确，键盘焦点可见。桌面和窄屏、200% 文字缩放做实际验证；首批桌面 Chromium，不宣称移动终端控制已经通过兼容验证。动画只用于必要状态反馈并支持 reduced-motion。
