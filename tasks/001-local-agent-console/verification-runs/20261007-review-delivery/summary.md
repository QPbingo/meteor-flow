## 使用与覆盖边界

启动步骤见 [使用说明](../../usage.md)：在 Node 24.21.0 下执行 `pnpm install --frozen-lockfile`、`pnpm build`，选择已存在的 herdr 会话后运行 `pnpm start -- serve --session <会话名>`，打开终端打印的本机入口。

网页实际业务链路中的 herdr 边界为模拟，两种真实 Agent 由应用层专项分别验证。herdr 0.9.0 仅契约核对；实际平台为 macOS arm64。30 秒压力窗口不证明长期无内存增长，物理休眠、完整屏幕阅读器和向真实模型发送 Ctrl-C 未单独实测。已确认的上游原子“身份校验并输入”接口缺失仍是能力限制，详见 [验证边界](../../verification-status.md)。

本地记录检查不证明测试穷尽，也不代替人工验收。没有提交、推送或部署；测试使用的独立资源已清理，用户现有 Agent 未停止。
